# AstrBot 屏幕查岗插件 (Screen Spy)

这是一个为 [AstrBot](https://github.com/AstrBotDevs/AstrBot) 设计的趣味互动插件。通过本插件，大语言模型（LLM）可以通过**函数调用（Tool Calling）**能力触发你本地电脑的真实屏幕截图，并自动交给视觉大模型进行分析。当 AI 觉得你太久没理它，或者对你在干什么感到好奇时，它就可以发起“查岗”，让你们的互动更加智能、真实有趣。可以搭配[手机查岗](https://github.com/nikonotnicotine/astrbot_plugin_phone_spy)

## 🌟 核心功能

- **原生函数调用 (Tool Calling)**：大模型会根据聊天上下文智能判断使用时机，自然发起查岗。
- **视觉模型分析**：截图不会直接发给用户，而是发送给你配置的视觉大模型（如 GPT-4o, Qwen-VL 等）。大模型“看”完后，会根据画面内容对你进行吐槽、质问或关心。
- **支持 VPS 远程部署**：原生支持 AstrBot 部署在云端 VPS，截图服务运行在本地电脑的场景（推荐配合 Tailscale 使用）。

## 🛠️ 准备工作：运行本地截图服务

由于 AstrBot 可能运行在容器或 VPS 中，它无法直接截取你本地电脑的屏幕。因此，你**必须**在**希望被查岗的那台电脑上**，运行一个配套的截图服务端程序。

**推荐使用打包好的 `.exe` 程序，它开箱即用，无需配置 Python 环境。**

1.  **[👉 点此前往下载截图服务端](https://github.com/nikonotnicotine/astrbot_plugin_screen_monitor_exe)**。
2.  按照需求下载文件。
3.  在你的电脑上**运行**。它会自动隐藏到系统右下角的托盘区，并保持后台工作。

## ⚙️ 插件配置 

如果你将 AstrBot 部署在 VPS 上，**强烈推荐使用 Tailscale** 或 ZeroTier 等虚拟局域网工具来连接你的 VPS 和本地电脑，确保数据传输安全。

1. 在 AstrBot 管理后台安装本插件。
2. 进入插件配置页面，填写以下信息：
   - **`vision_api_url`**: 视觉大模型的 API 地址（如 `https://api.openai.com/v1/chat/completions`）。
   - **`vision_api_key`**: 视觉大模型的 API 密钥。
   - **`vision_model_name`**: 视觉模型名称（如 `gpt-4o`, `qwen-vl-max` 等）。
   - **`vision_prompt`**: 发送给视觉大模型的分析提示词，可自定义以让 AI 重点关注屏幕的某些信息。
   - **`server_host`**: 填写你本地电脑的 IP 地址（如果在同一台电脑默认 `127.0.0.1`；如果用 Tailscale 通常是 `100.x.x.x`）。
   - **`server_port`**: 默认 `6878` (与截图服务端保持一致)。
3. 保存并重载插件。

## 🤖 大模型人设配置 (Prompt)

你只需要在 AstrBot 角色人设（System Prompt）中简单告诉 AI 它拥有这个超能力即可：

```text
    查岗功能
      说明:你现在拥有查看用户电脑屏幕的能力。当你认为用户长时间未回复你，或者你想主动知道用户在干什么时，请直接调用 `check_computer_screen` 工具获取用户屏幕的实时文字描述。获取到描述后，请根据你的人设作出反应。
```

## 💡 使用效果

配置完成后，当 AI 决定“查岗”时：
1. 它会在后台静默调用工具，你的电脑瞬间完成截图。
2. 视觉大模型飞速分析你的屏幕内容（比如“用户正在看B站番剧”）。
3. AI 拿到分析结果后，会在聊天框直接对你输出：“半天不理我，原来是在偷偷看番！”
```
